网站与 HTTP

从静态页面到应用入口。

静态文件与 SPA

内置

提供本地静态文件、单页应用回退；处理 ETag、条件请求和字节范围请求。

目录浏览与 WebDAV

内置

目录列表与文件浏览；WebDAV 文件操作可结合认证和权限配置。

Markdown 文档站

内置

将 Markdown 文件展示为带导航的文档页面，适合直接托管项目文档。

服务端模板

内置

HTML / 文本模板、请求变量与 JSON 数据获取；模板环境变量读取受白名单限制。

PHP / FastCGI

需后端

支持脚本选择、PATH_INFO 与前端控制器，再交给 FastCGI 后端执行。需要单独运行 PHP-FPM 等后端。

HTTP/1.1、HTTP/2 与 HTTP/3

按配置启用

提供 HTTP 服务及基于 QUIC 的 HTTP/3 入口；HTTP/3 需要 TLS 与可达的 UDP 监听端口。

路由与流量处理

用同一套路由承接不同应用。

多条件请求匹配

内置

按域名、路径、方法、请求头、查询参数和入口选择路由；支持正则与规则表达式。

重写与重定向

内置

路径重写、正则路径替换、前缀剥离与 HTTP 重定向。

请求头与响应头

内置

配置请求和响应头操作，并支持 CORS 跨域策略。

响应压缩

按配置启用

按客户端协商使用 gzip、Brotli 或 Zstandard；静态资源与动态响应均有处理路径。

反向代理缓存

按配置启用

代理响应缓存具有内存与磁盘容量控制、请求合并及重新验证逻辑；缓存行为由策略配置控制。

请求镜像

按配置启用

将请求复制到镜像后端，可用于旁路验证；需要配置镜像目标和相关限制。

反向代理与服务治理

让后端实例变化与入口规则解耦。

HTTP / HTTPS 上游

内置

反向代理到 HTTP 或 HTTPS 后端，支持连接池、Unix socket 及上游 TLS 策略。

WebSocket 与 gRPC

内置

处理 WebSocket 升级；通过 HTTP/2 / h2c 对接 gRPC 上游。

负载均衡

内置

内置轮询、IP Hash、加权轮询、P2C 与最少连接策略，并可通过 Go 插件注册自定义选路算法。

加权分流与会话保持

按配置启用

按后端权重分流；支持粘性 Cookie 和会话持久化配置。

重试与熔断

按配置启用

配置重试退避及熔断策略；重试还会检查方法和请求体是否适合重放。

健康状态与实例筛选

内置

根据实例可用状态及路由元数据选择后端，并处理被动健康反馈。

HTTPS、证书与 DNS

把证书生命周期纳入网关。

ACME 自动证书

按配置启用

自动申请与续期证书，包含 DNS-01、HTTP-01 与 TLS-ALPN-01 验证实现。域名、网络和提供商凭据须满足验证要求。

按需 TLS

按配置启用

在握手时为获准域名获取证书；实现包含域名准入及小时 / 天签发限额。

本地 CA 与自备证书

按配置启用

可加载 PEM 证书并监视变更，也可为允许的本地域名签发本地 CA 证书；客户端需要信任根证书。

OCSP Stapling

内置

为证书获取和附加 OCSP 响应，并通过后台任务刷新；实际可用性取决于证书与签发机构。

客户端证书校验与上游 mTLS

按配置启用

入口可校验客户端提交的证书；Litemesh 上游可使用其证书回调与信任策略建立 mTLS。需要配置对应 CA、身份和信任资源。

ECH 加密 ClientHello

按配置启用

管理 ECH 密钥、轮换与 DNS HTTPS 记录发布。需要支持 ECH 的客户端及具备 HTTPS 记录发布能力的 DNS 提供商。

动态 DNS

需外部服务

包含阿里云、Cloudflare、腾讯云、华为云提供商实现；记录更新与清理由配置和记录归属控制。

认证与访问控制

在应用之前处理身份与入口策略。

Basic Auth 与 API Key

按配置启用

基于用户名密码或 API Key 限制请求访问。

JWT 与 JWKS

按配置启用

验证 JWT，支持通过 JWKS 获取验签密钥。

OIDC 登录

需外部服务

接入 OIDC 身份提供商并处理登录与会话；需要外部身份服务。

Forward Auth

默认插件

把认证决策委托给外部认证端点。该 Go 插件已在当前默认命令入口注册，使用时仍须配置认证服务。

IP 限制与 CSRF

按配置启用

提供 IP 访问限制与 CSRF 校验中间件；客户端 IP 判断需要正确配置可信代理。

规则型 WAF 与扫描防护

按配置启用

对 URL 查询、路径及部分请求头匹配 SQL 注入、XSS、路径穿越和命令注入规则，并提供扫描防护。此处不宣称 OWASP CRS 兼容或完整请求体检测。

IDS 请求与响应钩子

扩展能力

支持请求检查、响应检查与治理决策，可接入 Go IDS 提供商；具体检测能力取决于提供商实现。

限流与资源控制

为连接、请求和带宽设置边界。

请求速率限制

按配置启用

提供本地限流实现及窗口限流器；可按配置使用 Redis 协调共享状态。

并发连接与带宽限制

按配置启用

配置连接并发和带宽策略；分布式连接租约需要相应共享存储。

请求体与超时控制

按配置启用

限制请求体大小，并配置后端请求期限与传输超时。

服务发现与容器平台

从已有服务目录生成入口。

Consul 与 Litemesh

需外部服务

读取服务目录、实例元数据与标签，跟随服务变化更新路由。

Docker 与 Swarm

需外部服务

发现 Docker 容器与 Swarm 服务，处理标签、网络及实例端点。需要 Docker API 访问权限。

Kubernetes Ingress

需外部服务

监听 Kubernetes 资源并将 Ingress 转换为网关配置；需要集群访问权限和相应 RBAC。

Kubernetes Gateway API

需外部服务

实现 Gateway、HTTPRoute、GRPCRoute、TLSRoute 和 ReferenceGrant 的处理路径；支持范围受资源类型及监听配置约束，不据此宣称完整规范认证。

标签 DSL 与 Magic Ingress

按配置启用

通过服务标签声明路由和策略，将目录中的后端合并到站点；也可配置自定义发现提供商。

四层代理与跨网络连接

HTTP 以外，也能连接服务。

TCP / UDP 转发

按配置启用

独立 stream 入口处理 TCP 与 UDP 流量，具有后端选路和空闲超时处理。

SNI / ALPN 分流

按配置启用

检查 TLS ClientHello，按 SNI / ALPN 选择入口；可在共享端口上组合 HTTP 与四层服务。

PROXY Protocol

按配置启用

提供入站 PROXY Protocol 解析，部署时须正确限制可信来源。

Connect 内网发布

按配置启用

内网 Home 主动连接 Cloud，建立认证的反向 HTTP/2 会话并发布服务；需要部署并配置两端。

Forward 安全隧道

按配置启用

通过带 Bearer 认证的 WSS 连接建立转发通道，用于跨网络访问。需要配置网关端与客户端。

SOCKS5 与正向代理

按配置启用

具有 stream SOCKS5 处理和 HTTP 正向代理插件。正向代理插件已在默认命令入口注册，使用前须配置访问策略。

配置、观测与运维

从配置文件到运行中的诊断。

YAML 配置与复用

内置

站点 YAML、简化语法、命名中间件与片段复用，可组合配置路由行为。

配置热加载

内置

监视 YAML 文件变更，并由应用校验和应用配置；监听器变更及长连接具有专门生命周期处理。

日志与指标

按配置启用

访问日志、异步日志分发、Prometheus 指标及状态展示，按配置暴露观测入口。

分布式追踪

需外部服务

处理追踪上下文，批量向收集器导出 OTLP/HTTP JSON。需配置收集端；并非 OTLP/gRPC 导出。

MCP 管理与诊断

按配置启用

内置 MCP 服务，连接配置、证书、服务发现和运行时中间件流水线诊断；需要配置访问入口与认证。

命令行与系统服务

内置

提供运行、构建、插件管理、健康检查、Connect / Forward 及 systemd 服务管理命令。

事件与插件

区分已有实现与可扩展接口。

NATS 与 SSE 事件通知

默认插件

提供 NATS action、通知传输和浏览器 SSE 订阅，包含订阅配额与慢客户端处理。默认编入，可通过 nonats 标签移除；需要配置 NATS 服务。

Webhook 事件投递

需外部服务

提供 Webhook 投递实现，可用于事件通知集成。接收端需要自行部署。

Go 编译期插件

扩展能力

公开 action、中间件、负载均衡、DNS、发现与 IDS 等接口。自定义插件须实现并注册后重新构建；接口存在不代表所有第三方服务已接入。

WASM IDS

可选构建

基于 wazero 加载 IDS WASM 插件并支持目录监视。必须使用 -tags wasmids 构建，再启用 ids_wasm 配置；默认构建不含运行时。

没有匹配的功能，请更换关键词或重置筛选。

从一个站点开始

选择需要的入口和策略，再逐步接入服务发现、认证与观测。

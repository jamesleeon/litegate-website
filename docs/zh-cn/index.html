LiteGate 文档中心

LiteGate 是单一二进制的 HTTP / TCP 网关：放在网站、API 和内网服务前面，负责接收流量、自动配置 HTTPS、按规则转发。本文档描述当前代码的使用方式。

中文 · English

不需要从头读到尾。建议按下面四步走：先跑通 → 找到自己的场景 → 需要时查参考 → 上线前看部署。

第一步：跑起来（约 5 分钟）

  1. 安装：下载二进制、Docker 或源码构建
  2. 快速开始：零配置启动，写第一个站点
  3. 入门案例：一个站点跑起来：反向代理、静态站、HTTPS、负载均衡，每段配置都由自动化测试验证，复制即可用

# LiteGate Service Tags

The service tag documentation has three parts:

- [Service Tag Architecture](user/02-concepts/tag-architecture.md): why tags are designed this way, how they become routes, routing vs instance tags, tags vs site YAML, troubleshooting.
- [Service Tags Guide](user/03-configuration/tag-dsl.md): how to write them by scenario: the shortcut, named Routers, service policy, middlewares, IDS, dedicated ports.
- [Service Tag Reference](user/03-configuration/tag-reference.md): every tag's values and meaning plus the defaults, generated from the parser's property lists.

Where to write tags (Consul, Litemesh, Docker, Kubernetes) is covered in [Service Registration](service_registration_guide.md).

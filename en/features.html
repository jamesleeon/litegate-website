Websites and HTTP

From static pages to application entry points.

Static files and SPAs

Built in

Serve local files and single-page application fallbacks, with ETags, conditional requests and byte-range requests.

Directory browsing and WebDAV

Built in

Browse directories and files, and combine WebDAV file operations with authentication and permissions.

Markdown documentation

Built in

Present Markdown files as documentation pages with navigation, making it easy to host project docs directly.

Server-side templates

Built in

Render HTML and text templates using request variables and JSON data. Environment variable access is restricted to an allowlist.

PHP / FastCGI

Backend required

Select scripts, handle PATH_INFO and front controllers, and send execution to a FastCGI backend. Requires a separate backend such as PHP-FPM.

HTTP/1.1, HTTP/2 and HTTP/3

Configurable

Serve HTTP traffic and QUIC-based HTTP/3. HTTP/3 requires TLS and a reachable UDP listener.

Routing and traffic handling

Bring different applications into one routing system.

Request matching

Built in

Select routes by hostname, path, method, headers, query parameters and entry point, with regular expressions and rule expressions.

Rewrites and redirects

Built in

Rewrite paths, replace paths with regular expressions, strip prefixes and issue HTTP redirects.

Request and response headers

Built in

Configure request and response header operations and CORS policies.

Response compression

Configurable

Negotiate gzip, Brotli or Zstandard with clients for static resources and dynamic responses.

Reverse proxy caching

Configurable

Cache proxy responses with memory and disk capacity controls, request coalescing and revalidation. Policies determine caching behavior.

Request mirroring

Configurable

Copy requests to a mirror backend for out-of-band validation. Configure the mirror target and resource limits.

Reverse proxy and service policies

Keep entry-point rules independent of backend instance changes.

HTTP / HTTPS upstreams

Built in

Proxy requests to HTTP or HTTPS backends with connection pooling, Unix sockets and upstream TLS policies.

WebSocket and gRPC

Built in

Handle WebSocket upgrades and connect to gRPC upstreams over HTTP/2 or h2c.

Load balancing

Built in

Choose round robin, IP hash, weighted round robin, P2C or least connections, and register custom algorithms with Go plugins.

Weighted traffic and session affinity

Configurable

Distribute traffic by backend weight and configure sticky cookies and session persistence.

Retries and circuit breakers

Configurable

Configure retry backoff and circuit breakers. Retries check whether the request method and body are suitable for replay.

Health and instance filtering

Built in

Select backends by availability and routing metadata, and process passive health feedback.

HTTPS, certificates and DNS

Manage the certificate lifecycle within the gateway.

Automatic ACME certificates

Configurable

Obtain and renew certificates using DNS-01, HTTP-01 or TLS-ALPN-01 challenges. Domains, network access and provider credentials must meet validation requirements.

On-demand TLS

Configurable

Obtain certificates for authorized domains during the TLS handshake, with domain admission controls and hourly or daily issuance limits.

Local CA and custom certificates

Configurable

Load PEM certificates and watch for changes, or issue local CA certificates for allowed local domains. Clients must trust the root certificate.

OCSP stapling

Built in

Fetch, staple and refresh OCSP responses in the background. Availability depends on the certificate and issuer.

Client certificates and upstream mTLS

Configurable

Validate client certificates presented at ingress. Litemesh upstreams can use certificate callbacks and trust policies for mTLS. Requires CA, identity and trust configuration.

Encrypted ClientHello (ECH)

Configurable

Manage and rotate ECH keys and publish DNS HTTPS records. Requires ECH-capable clients and a DNS provider that can publish HTTPS records.

Dynamic DNS

External service

Integrate with Alibaba Cloud, Cloudflare, Tencent Cloud and Huawei Cloud. Configuration and record ownership control updates and cleanup.

Authentication and access

Apply identity and access policies before requests reach applications.

Basic Auth and API keys

Configurable

Restrict access using usernames and passwords or API keys.

JWT and JWKS

Configurable

Verify JWTs and retrieve verification keys through JWKS.

OIDC login

External service

Connect to an OIDC identity provider and manage login and sessions. Requires an external identity service.

Forward Auth

Default plugin

Delegate authentication decisions to an external endpoint. This Go plugin is included in the default command build and requires an authentication service.

IP restrictions and CSRF

Configurable

Apply IP access restrictions and CSRF checks. Configure trusted proxies correctly when determining client IP addresses.

Rule-based WAF and scan protection

Configurable

Match SQL injection, XSS, path traversal and command injection patterns in URL queries, paths and selected headers, with scan protection. Does not provide full request-body inspection or claim OWASP CRS compatibility.

IDS request and response hooks

Extension

Inspect requests and responses and apply governance decisions through Go IDS providers. Detection capabilities depend on the provider.

Rate limits and resources

Set boundaries for connections, requests and bandwidth.

Request rate limits

Configurable

Apply local rate limits and window-based limiters, with optional Redis coordination for shared state.

Concurrent connections and bandwidth

Configurable

Configure connection concurrency and bandwidth policies. Distributed connection leases require shared storage.

Request size and timeouts

Configurable

Limit request body size and configure backend request deadlines and transport timeouts.

Discovery and containers

Create entry points from existing service catalogs.

Consul and Litemesh

External service

Read service catalogs, instance metadata and tags, and update routes as services change.

Docker and Swarm

External service

Discover Docker containers and Swarm services, including labels, networks and instance endpoints. Requires Docker API access.

Kubernetes Ingress

External service

Watch Kubernetes resources and translate Ingress resources into gateway configuration. Requires cluster access and appropriate RBAC permissions.

Kubernetes Gateway API

External service

Handle Gateway, HTTPRoute, GRPCRoute, TLSRoute and ReferenceGrant resources. Support depends on resource types and listener settings; this is not a claim of full specification certification.

Tag DSL and Magic Ingress

Configurable

Declare routes and policies through service tags and merge catalog backends into sites. Custom discovery providers are also supported.

Layer 4 and connectivity

Connect services beyond HTTP.

TCP / UDP forwarding

Configurable

Handle TCP and UDP traffic on dedicated stream entry points, with backend selection and idle timeout handling.

SNI / ALPN routing

Configurable

Inspect TLS ClientHello messages and route by SNI or ALPN. Combine HTTP and layer 4 services on a shared port.

PROXY protocol

Configurable

Parse incoming PROXY protocol headers. Restrict trusted sources appropriately when deploying.

Connect private service publishing

Configurable

An internal Home node initiates an authenticated reverse HTTP/2 session to a Cloud node to publish services. Deploy and configure both ends.

Forward secure tunnels

Configurable

Establish forwarding channels over WSS with Bearer authentication for access across networks. Configure both the gateway and client.

SOCKS5 and forward proxy

Configurable

Handle SOCKS5 streams and HTTP forward proxy traffic. The forward proxy plugin is included in the default command build; configure access policies before use.

Configuration and operations

From configuration files to runtime diagnostics.

YAML configuration and reuse

Built in

Combine site YAML, shorthand syntax, named middleware and reusable snippets to configure routing behavior.

Configuration hot reload

Built in

Watch YAML changes, validate configuration and apply updates, with dedicated lifecycle handling for listener changes and long-lived connections.

Logs and metrics

Configurable

Access logs, asynchronous log dispatch, Prometheus metrics and status views, with observability endpoints enabled through configuration.

Distributed tracing

External service

Process trace context and export batches as OTLP/HTTP JSON to a configured collector. OTLP/gRPC export is not provided.

MCP management and diagnostics

Configurable

Use the built-in MCP service for configuration, certificates, service discovery and runtime middleware pipeline diagnostics. Configure access and authentication.

Command line and system services

Built in

Run the gateway, build binaries, manage plugins, check health, operate Connect and Forward, and manage systemd services from the command line.

Events and plugins

Connect event systems and extend gateway behavior.

NATS and SSE notifications

Default plugin

Use NATS actions, notification transport and browser SSE subscriptions, with subscription quotas and slow-client handling. Included by default; the nonats build tag removes it. Requires a configured NATS service.

Webhook delivery

External service

Deliver events to Webhook integrations. Requires a separately deployed receiver.

Go compile-time plugins

Extension

Extend actions, middleware, load balancing, DNS, discovery and IDS through public interfaces. Implement and register custom plugins, then rebuild. An interface alone does not provide every third-party integration.

WASM IDS

Optional build

Load IDS WASM plugins with wazero and watch the plugin directory. Build with -tags wasmids and enable ids_wasm. The default build excludes this runtime.
